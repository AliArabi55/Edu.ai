# أزرار التنقل التفاعلية - React & Tailwind CSS

مشروع React يحتوي على أزرار تنقل تفاعلية مصممة باستخدام Tailwind CSS مع تأثيرات جميلة ومتقدمة.

## ✨ المميزات

### 🎯 تأثيرات تفاعلية متقدمة:
- **تأثير Hover**: تغيير اللون والحجم عند التأشير بالماوس
- **تأثير Click**: ضغطة لأسفل مع تأثير الموجة (Ripple Effect)
- **تأثير Focus**: حدود ملونة عند التركيز على الزر
- **انتقالات سلسة**: جميع التأثيرات تتم بسلاسة

### 🎨 التصميم:
- **حواف دائرية**: `rounded-xl` لجميع الأزرار
- **ظلال خفيفة**: `shadow-md` و `shadow-lg` عند التفاعل
- **ألوان متدرجة**: استخدام `gradient` للخلفيات
- **أيقونات SVG**: أيقونات واضحة لكل زر
- **تصميم متجاوب**: يعمل على جميع أحجام الشاشات

### 🔧 الأزرار المتاحة:
- أزرار الاتجاهات: السابق، التالي، لأعلى، لأسفل، يمين، يسار
- أزرار النظام: الرئيسية، الإعدادات، المساعدة، الخروج
- جميع الأزرار قابلة للتخصيص بسهولة

## 🎛️ التخصيص

### تغيير الألوان:
```jsx
// في NavigationButtons.jsx
className="bg-blue-500 hover:bg-blue-600"
// يمكن تغييرها إلى أي لون آخر مثل:
className="bg-red-500 hover:bg-red-600"
```

### تغيير الأحجام:
```jsx
// تغيير الحجم
className="px-8 py-4"  // كبير
className="px-6 py-3"  // متوسط  
className="px-4 py-2"  // صغير
```

### إضافة أزرار جديدة:
```jsx
<button
  onClick={() => handleClick('اسم الزر')}
  className="[الكلاسات المطلوبة]"
>
  <svg>...</svg>  {/* أيقونة اختيارية */}
  اسم الزر
</button>
```

## 🎨 أنواع التأثيرات المستخدمة

### 1. تأثيرات الحجم (Scale):
```css
hover:scale-105     /* تكبير 5% عند Hover */
active:scale-95     /* تصغير 5% عند Click */
```

### 2. تأثيرات الحركة (Transform):
```css
hover:-translate-y-1    /* رفع لأعلى */
hover:translate-y-1     /* نزول لأسفل */
hover:-translate-x-1    /* حركة لليسار */
hover:translate-x-1     /* حركة لليمين */
```

### 3. تأثيرات الظل (Shadow):
```css
shadow-md           /* ظل متوسط */
hover:shadow-lg     /* ظل كبير عند Hover */
hover:shadow-xl     /* ظل أكبر */
```

### 4. تأثير الموجة (Ripple):
- يتم إنشاؤه ديناميكياً بـ JavaScript
- يظهر دائرة متوسعة من نقطة الضغط
- يختفي تلقائياً بعد 0.6 ثانية

1. تأكد من تثبيت Tailwind CSS بشكل صحيح
2. تحقق من إعدادات `tailwind.config.js`
